# v0.1.3-preview 실기기 촬영

[English](device-capture.md) · [프로젝트 소개](../README.ko.md) · [영상·장면 설명](videos/README.ko.md)

**2026-11-17 실물 태블릿 한 대에서 관찰했습니다(observed, n=1).** 촬영 전
설치 APK를 태블릿에서 다시 추출해 공개 배포본과 바이트 단위로 일치하는지 확인했습니다.
기존 게스트의 제한된 동작 사례이며 성능 측정·전체 설치·장기 안정성 검사가 아닙니다.

기존 게스트의 자원 설정을 바꾸지 않았습니다. 이번 4코어·4GB는 새로운 추천값이
아니며, 보수적인 시작값은 여전히 2 vCPU / 2048 MiB입니다. 게스트와 Android의
시간대가 달라 표시 시각을 성능 측정에 사용하면 안 됩니다.

## 실제로 진행한 내용

공개 APK에서 기존 게스트를 실행해 로컬 로그인 후 바탕화면을 확인했습니다.
복원된 개인 터미널 창은 가리고 다른 창은 최소화한 뒤 녹화를 시작했습니다.
영상에는 Dock에서 Safari 열기, 앱 도구로 공개 주소 `https://example.com` 입력,
웹 페이지 표시가 이어집니다. Safari 스크린샷도 같은 세션에서 촬영했습니다.
촬영 후 앱의 **Mac 종료**로 수동 종료했으며 VM 자동 시간 제한은 적용하지 않았습니다.

이 개발자 소유 연구 설치에는 기존·배포 서명키를 모두 보유하고 있어, 비공개 Android
서명키 이전용 APK를 거쳐 정확한 공개 APK로 업데이트했습니다. 먼저 별도 에뮬레이터에서
두 업데이트 후 자체 데이터 표식이 유지되는지 시험했습니다. 실물 태블릿의 앱 삭제·
데이터 초기화·macOS 재설치는 하지 않았습니다. **다른 키로 서명된 연구 APK에
일반적으로 적용할 수 있는 이전 도구가 아닙니다.** 다른 설치는
[서명·데이터 보존 안내](apk-release.ko.md)를 따르세요. 이전용 APK·서명 자료는
공개하지 않으며 기존 공개 릴리스도 교체하지 않았습니다.


배포 앱에서 저장한 이번 세션 로그는 부팅 포함 758.8초, `timeout=0`,
`panic_events=0`, `flush_failed=0`, `EXIT_CODE=0`과 포그라운드 서비스·화면 깨움
해제를 기록했습니다. 촬영 전후 태블릿 부팅 식별값도 같았습니다. 이번 세션의 관측이며
과거 재부팅 원인이 해결됐거나 장기 검사를 통과했다는 뜻은 아닙니다.

  검토했습니다. 모든 인코딩 프레임을 수동 검토했다는 뜻은 아닙니다. 검토한 공개 미디어에
  계정·암호·기기 일련번호·개인 터미널·로컬 경로는 보이지 않았습니다. 로그인은 녹화 전에 마쳤습니다.
- 크기·체크섬은 [촬영 기록](../android/publication/device-capture-2026-11-17.json)에 있습니다.
  이름을 지정한 미디어만 내보내며 원시 로그·게스트 디스크·계정·미검토 영상·서명 자료는 제외합니다.

## 한계

페이지가 한 번 열렸다고 네트워크 신뢰성이 입증되지는 않습니다. 제한된 세션 한 번으로
과거 GPU 오류·태블릿 재부팅 원인, 장기 안정성·실사용성·네이티브 수준 속도가 해결됐다고
주장하지 않습니다. 통제된 전후 속도 비교도 하지 않았습니다. 실물 외부 입력·다른 기기와 GPU·
16K 실행 페이지·새 자동 설치 전체 과정·macOS 26/27은 미검증입니다.
이전 스크린샷·슬라이드 영상은 [역사적 자료](images/README.md)로 구분해 유지합니다.

타사 UI·그림·상표의 권리는 각 권리자에게 있으며 프로젝트 소스 라이선스로 재허가하지 않습니다.
